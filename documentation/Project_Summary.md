# Project Summary

## Project Title

Spotify Music Analysis Dashboard

## Overview

The Spotify Music Analysis Dashboard is a Power BI project designed to explore music trends, artist popularity, genre performance, and audio characteristics using Spotify data.

The dashboard converts raw music data into interactive visualizations that help users understand listener preferences and track performance.

## Objectives

- Analyze track popularity across artists and genres
- Compare artist performance based on popularity metrics
- Study genre distribution and trends
- Evaluate music characteristics such as energy, valence, and danceability
- Build an interactive dashboard for music analytics

## Tools Used

- Power BI
- Microsoft Excel

## Dashboard Highlights

- Top 10 Most Popular Tracks
- Most Popular Artists Analysis
- Genre Performance Dashboard
- Energy vs Valence Mood Map
- Interactive Artist and Genre Filters
- KPI Cards for Audio Features

## Key Insights

- Popular tracks generally exhibit high energy and danceability scores.
- Certain artists consistently achieve higher average popularity.
- Different genres display unique mood and energy characteristics.
- Genre preferences significantly influence track popularity.
- Audio features can help explain listener engagement patterns.

## Outcome

The project demonstrates how data analytics and visualization techniques can be applied to music datasets to uncover trends, compare performance, and generate meaningful insights.

## Conclusion

The Spotify Music Analysis Dashboard showcases the use of Power BI for music analytics by transforming complex audio and popularity data into actionable insights through interactive visual storytelling.
