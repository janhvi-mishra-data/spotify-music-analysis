# Dataset Information

## Dataset Name

Spotify Tracks Dataset

## Description

The dataset contains information about songs, artists, genres, and audio features collected from Spotify. It is used to analyze music trends, track popularity, artist performance, and listener preferences through interactive visualizations.

## Key Attributes

| Attribute | Description |
|------------|------------|
| Track Name | Name of the song |
| Artist Name | Name of the artist |
| Genre | Music genre/category |
| Popularity | Popularity score of the track |
| Danceability | Measure of how suitable a track is for dancing |
| Energy | Intensity and activity level of the track |
| Valence | Musical positivity or happiness score |
| Tempo | Speed of the track in beats per minute |
| Acousticness | Confidence measure of whether a track is acoustic |
| Instrumentalness | Predicts whether a track contains vocals |
| Liveness | Detects the presence of an audience |
| Speechiness | Measures spoken words within a track |

## Data Preparation

The dataset was prepared for analysis using the following steps:

- Removed missing values
- Cleaned inconsistent data entries
- Standardized genre names
- Verified numerical audio feature values
- Prepared calculated measures for dashboard KPIs

## Business Use Cases

- Music trend analysis
- Artist performance evaluation
- Genre popularity analysis
- Audience preference analysis
- Music recommendation research
- Entertainment industry analytics

## Visualization Tool

Power BI was used to build interactive dashboards and generate insights from the Spotify dataset.
